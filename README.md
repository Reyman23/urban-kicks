Descripción

URBAN KICKS es un sitio web de una tienda ficticia de zapatillas urbanas. Permite conocer la tienda, ver distintos modelos de zapatillas y contactarse mediante un formulario.

Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

Cómo usar el sitio:
1. Abrir `index.html` para ingresar a la página principal.
2. Entrar en Productos para ver los modelos disponibles.
3. Entrar en Contacto para completar el formulario.
